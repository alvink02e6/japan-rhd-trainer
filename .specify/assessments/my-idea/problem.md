# Problem Definition: 台灣左駕旅客於赴日自駕前缺乏零門檻、主動式的右駕認知決策與日本差異號誌演練管道

- **Slug**: my-idea
- **Created**: 2026-11-13（Updated: 2026-11-24 via `/grill-me` 定案）
- **Inputs used**: intake.md, research.md

## Problem Statement

習慣左駕（靠右行駛）的台灣旅客在前往日本（沖繩、北海道等熱門自駕地區）租車旅遊前，雖可觀看靜態文章、YouTube 影片或下載高門檻的通用駕駛遊戲，卻缺乏能在隨身手機瀏覽器上「免下載、3–5 分鐘內」針對日本高風險右駕差異（包含右轉事故率達日籍駕駛 2.4–2.7 倍的多車道右轉大彎、上下兩排矢印式信号機、止まれ紅倒三角停讓、及右側方向燈／左側雨刷反向操作）進行主動決策演練的輕量管道，導致剛取車上路與遇複雜路口時承受高度焦慮與違規、逆向擦撞風險。

## Affected Users & Stakeholders

- **Users**: 計畫赴日本（首波鎖定沖繩、北海道等台灣自由行高自駕比例地區）租車自駕、平時習慣台灣左駕與台灣號誌邏輯的駕駛人及其同行旅伴（副駕） — 2024–2025 年台灣訪日旅客連年突破 600–676 萬人次，旅客在出發前數日高度集中於 LINE 群組、FB 社團與搜尋引擎查閱自駕攻略，最需克服「右轉誤入對向車道、看錯橫排／上下排箭頭紅綠燈、止まれ未完全靜止、轉彎誤撥雨刷」等高頻失誤（源自 `research.md`）。
- **Stakeholders**: 獨立開發者／小型獨立團隊 — 以「免費輕量工具起手、零商業圖資邊際成本、2–3 週精實行為驗證實驗」為核心策略，保留未來依實測數據擴展至進階主題包付費解鎖（Web／Native IAP）、高客單日本租車／旅平險聯盟分潤（Affiliate）或 B2B2C 租車行合作的商業空間。

## Goals

- 讓台灣赴日自駕旅客在出發前 3–5 分鐘內，無需下載大型原生 App 即可完成高密度的日本差異號誌動態判讀與第一人稱右駕關鍵決策演練。
- 針對日本官方統計外籍駕駛最高風險情境（右轉大彎車道選擇、上下排矢印式信号機、止まれ紅倒三角停讓、右側方向燈不誤觸左側雨刷）建立主動式短期反射記憶，降低實際取車上路初期的焦慮與失誤率。
- 透過極低摩擦的社群分享回饋機制（例如行前診斷評級與旅伴挑戰），在零廣告投放預算（Zero-CAC）下驗證自然擴散與進階情境解鎖需求。

## Non-Goals

- 不取代正式汽車駕照考照訓練、道路駕駛教練課程或日本法定交通法規資格認證。
- MVP 階段不支援「匯入全球或日本任意規劃導航路線進行全程連續模擬」（因商業街景計費成本過高且開放圖資全城 3D 渲染不符行動端效能與 2–3 週投入上限）。
- 不追求需要高階桌機顯卡、大型實體方向盤外設，或以手寫無引擎底層 Shader（如 `Abyssal Garden` 模式）追求極致畫面炫技的擬真賽車物理模擬。
- 不作為實際在日本行車過程中的即時衛星導航系統（聚焦於「出發前」之預習與認知演練）。
- MVP 階段不實作正式金流結帳或上架 iOS / Android 原生 App Store（先以零金流 Fake Door 與分享解鎖完成真實需求驗證）。

## Success Metrics

以下指標為 MVP 上線後 **30 天行為驗證實驗期** 之量化達標基準：

- **單次體驗完課率（Engagement / Completion）**：進入工具之使用者，完成「日本差異號誌動態問答 ＋ 3D 駕訓熱身場」首套體驗的比例 **≥ 50%**，且平均單次完成時間控制在 **3–5 分鐘**（baseline: unknown，上線後由事件埋點量測）。
- **關鍵右駕情境學習遷移成效（Behavioral Learning Gain）**：重複演練者在關鍵失誤項（轉彎誤撥雨刷、止まれ未完全停讓、右轉誤入對向車道、上下排箭頭號誌誤判）之錯誤率較初次嘗試下降 **≥ 40%**（baseline: 初次作答／初試錯誤率）。
- **需求強度與自然擴散信號（WTP & Growth Validation）**：完成首套體驗者中，點擊鎖定之進階實戰主題包（Fake Door 付費意願測試）或透過「分享給同行旅伴」解鎖的比例 **≥ 10%**（baseline: unknown；以此作為 Phase 2 是否投入進階地圖開發、原生 App IAP 或租車聯盟導購的放行門檻）。
- **出發前準備信心度提升（Qualitative / Post-Session Pulse）**：完課後 1 題輕量自評中，表示「對赴日右駕與日本號誌更有把握」的比例 **≥ 75%**（baseline: unknown）。
- **單位經濟成本永續性（Unit Cost Cap）**：零商業地圖／街景 API 費用，採純靜態 PWA 託管，單一訪客邊際基礎設施成本 **≤ NT$0.1**（baseline: `research.md` 顯示既有街景模擬器因 API 計費過高關閉服務）。

## Cost of Inaction

若不解決此問題，每年逾 600 萬人次的台灣赴日旅遊基本盤中，大量首度或低頻赴沖繩、北海道自駕的旅客仍只能依賴被動閱讀靜態號誌圖表、觀看 YouTube 影片，或下載高阻力卻割裂的通用外國駕駛 App，無法在出發前針對日本特有的上下排箭頭號誌、止まれ停讓、左右撥桿反轉與高達 2.4–2.7 倍事故風險的右轉大彎進行主動式演練，持續承擔取車初期的心理壓力與交通意外風險。
