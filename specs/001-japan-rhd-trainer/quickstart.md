# Quickstart & Validation Guide: 台灣赴日自駕右駕認知與號誌演練工具 (`001-japan-rhd-trainer`)

**Date**: 2026-11-27
**Feature**: [spec.md](./spec.md)
**Contracts**: [telemetry-events.md](./contracts/telemetry-events.md), [ui-share-and-iab.md](./contracts/ui-share-and-iab.md)

本指南說明於實作完成後，如何在本地開發環境與行動裝置／社群內建瀏覽器上執行建置、自動化測試與端對端驗收情境。

---

## 1. 環境需求（Prerequisites）

- **Node.js**: `v20+`（本機已驗證安裝 `v24.21.0`）
- **npm**: `v10+`（本機已驗證安裝 `11.19.0`）
  > **Windows PowerShell 注意事項**：若系統預設 PowerShell ExecutionPolicy 為 `Restricted` 導致直接輸入 `npm` 報錯（`npm.ps1 cannot be loaded`），請改用 **`npm.cmd`**（例如 `npm.cmd install`、`npm.cmd test`），或在當前終端機工作階段先執行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`。
- **測試裝置（發布前必測門檻，依憲章品質閘門 #3）**：至少 1 台 iOS 手機（Safari + LINE/FB 內建瀏覽器）與 1 台 Android 手機（Chrome + LINE/FB 內建瀏覽器）。

---

## 2. 安裝、測試與建置指令

於專案根目錄（`c:\Users\alvinkuo\Desktop\Spec kit`）執行：

```powershell
# 1. 安裝相依套件
npm.cmd install

# 2. 執行純領域交通規則單元測試（憲章原則 V：必須 100% 通過）
npm.cmd run test:unit

# 3. 執行型別檢查與生產環境靜態打包
npm.cmd run build

# 4. 啟動本地預覽伺服器（預設監聽區網 IP 供手機同 Wi-Fi 實測）
npm.cmd run preview -- --host
```

（選用）執行行動端 Viewport 與模擬 In-App Browser 端對端自動化測試：

```powershell
npm.cmd run test:e2e
```

## 3. 端對端驗收情境（End-to-End Validation Scenarios）

### 情境 A：首屏載入預算與 P1 動態號誌問答＋診斷卡（對應 `US1`, `SC-001`）
1. 檢查 `dist/` 產出之首屏主 JS 分塊（不含延遲載入之 3D 引擎分塊）gzip 後體積 `< 60 KB`。
2. 以手機開啟預覽網址（或加上 `?ref=buddy` 驗證旅伴邀請歡迎橫幅），確認首次點擊開始時必須先彈出行前教育安全免責聲明。
3. 完成 8–10 題台日差異動態號誌問答：
   - 驗證「紅燈＋下排綠箭頭」選依箭頭通行判定為正確；
   - 驗證「純紅燈無箭頭」選紅燈轉彎判定為錯誤並顯示日本嚴禁紅燈轉彎解析。
4. 確認結算頁自動產生個人化「赴日右駕存活／翻車診斷卡」圖片（支援長按儲存）及「傳送到 LINE 群組」／「複製挑戰連結」按鈕。

### 情境 B：P2 駕訓熱身場與左右撥桿陷阱（對應 `US2`, `FR-005`–`FR-008`）
1. 進入「駕訓熱身場」，確認視角為右側駕駛座且具備左前車頭距離參考線。
2. 將手機切換為**靜音模式**，故意點擊**左側撥桿區**：確認前擋風玻璃立即播放雨刷乾刷動畫與頂部文字提醒，並記錄 1 次「左側誤觸雨刷」（驗證無音訊對等回饋 `FR-011`）。
3. 點擊**右側方向燈**並完成左轉小彎與右轉大彎進入左側車道，確認過關。

### 情境 C：P3 日本市區高風險路口與重複挑戰進步計算（對應 `US3`, `SC-003`, `SC-004`）
1. 第 1 次進入「市區實戰第 1 關」：
   - 故意在紅倒三角「止まれ」停止線前僅減速滑行未滿 1 秒即通過 → 確認觸發「止まれ未完全靜止」失誤提醒；
   - 故意於十字路口右轉時切入右側對向車道 → 確認立即觸發逆向攔截警示與正確「右轉大彎入左側車道」圖解。
2. 第 2 次重複挑戰同一關卡：在「止まれ」完全煞停滿 1 秒、依下排右轉箭頭禮讓對向車與斑馬線行人後轉入左側車道零失誤過關。
3. 確認結算畫面並列顯示首次與本次失誤數及錯誤下降百分比（驗證 `>= 40%` 計算邏輯），並可提交 1 題行前信心自評。

### 情境 D：P4 Fake Door 需求測試、旅伴分享解鎖與 LINE/FB 內建瀏覽器防護（對應 `US4`, `SC-005`, `SC-006`）
1. 將預覽網址貼入個人 LINE 聊天室（Keep 筆記）並於 **LINE 內建瀏覽器**開啟：
   - 在駕駛關卡中上下左右滑動，確認**不會觸發下拉重新整理或視窗縮放**，且底部左右撥桿不被工具列遮擋；
   - 中途切換至其他 App 再切回 LINE，確認關卡已自動進入「已暫停」狀態。
2. 點擊「北海道冬季雪地包」預告卡，確認清楚顯示「尚在籌備統計中，本次不會收取任何費用」且無任何付款表單。
3. 點擊「分享給同行旅伴免費解鎖市區實戰第 2 關」並完成 LINE 分享或連結複製，確認「市區實戰第 2 關」立即解鎖可進入遊玩，且結算頁外部旅遊資源清楚標示「合作推薦／外部資源」標籤。
